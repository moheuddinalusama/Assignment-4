৩. ইভেন্ট বাবলিং কী? এবং এটি কীভাবে কাজ করে?

৩নং প্রশ্নের উত্তর: Child এ ক্লিক করলে event উপরে parent  document পর্যন্ত চলে যায়।



৪. জাভাস্ক্রিপ্টে ইভেন্ট ডেলিগেশন কী? এটি কেন কার্যকর?

৪নং প্রশ্নের উত্তর: Parent এ একবার event দিলে, তার ভিতরের সব child handle করা যায়।


৫. preventDefault()এবং stopPropagation() পদ্ধতির মধ্যে পার্থক্য কী?
